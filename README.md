Vice Meridian is an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PS5. It includes a spoiler-safe checklist, per-trophy citations, saved tallies with JSON backups, a three-stage platinum roadmap, and a research audit that shows which unlock methods are still open in the guide’s research snapshot.

## Run it

```sh
node serve.ts
```

Open [http://localhost:8080](http://localhost:8080).
